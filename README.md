# ACOUSTIC_SYNC_TX (STM32G474CET3)

Прошивка акустического передатчика (TX) межприборной синхронизации на базе микроконтроллера **STM32G474CET3 (LQFP48)**.

## Основные параметры
- **Микроконтроллер**: STM32G474CET3 (LQFP48)
- **Тактовая частота**: 84 МГц (HSE 16 МГц -> PLL)
- **Несущая частота**: 154.411 кГц (TIM1 комплементарный ШИМ)
- **Код синхронизации**: 31-битная М-последовательность Баркера (66 периодов на бит = 2046 периодов в пачке)
- **Период следования пачек**: ровно 2.000 с (168 000 000 тактов таймера TIM5)
- **Управление питанием**: динамическое включение/выключение питания TPS (`PB14`) и мостового драйвера (`PB11`) для минимизации энергопотребления в паузах.

## Назначение выводов
| Вывод | Имя в коде | Функция / Режим | Описание |
|---|---|---|---|
| **PA0** | `SYNC_OUT` | `GPIO_Output` | Выход импульса синхронизации |
| **PA5** | `LED` | `GPIO_Output` | Светодиодная индикация излучения |
| **PA8** | `TIM1_CH1` | `PWM Output` | Прямой ШИМ несущей 154.4 кГц |
| **PB13** | `TIM1_CH1N` | `PWM Output` | Инверсный ШИМ несущей 154.4 кГц |
| **PB11** | `DIS_DRV` | `GPIO_Output` | Разрешение драйвера моста (0 - ON, 1 - OFF) |
| **PB14** | `DIS_TPS` | `GPIO_Output` | Питание преобразователя TPS (1 - ON, 0 - OFF) |
| **PA9** | `USART1_TX` | `UART_TX` | Сервисный UART интерфейс (115200) |
| **PA10** | `USART1_RX` | `UART_RX` | Сервисный UART интерфейс (115200) |
| **PA13** | `SWDIO` | `Serial Wire` | Отладка SWD |
| **PA14** | `SWCLK` | `Serial Wire` | Отладка SWD |
