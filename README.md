# ACOUSTIC_SYNC_TX (STM32G474CET3)

Прошивка передатчика (TX) электромагнитного/акустического канала межприборной синхронизации скважинного каротажного комплекса на базе микроконтроллера **STM32G474CET3 (LQFP48)**.

---

## 1. Назначение и физический принцип
Передатчик предназначен для формирования стабильного периодического синхросигнала, передаваемого через акустический изолятор или электромагнитную индукционную линию связи между скважинными модулями (модулем излучателей и модулем регистрации).

- **Период повторения**: ровно **$2.000000\text{ с}$** ($168\,000\,000$ тактов при $84\text{ МГц}$).
- **Несущая частота**: **$154.411\text{ кГц}$** ($84\text{ МГц} / 544$).
- **Код синхронизации**: 31-битная псевдослучайная M-последовательность (полином $X^5 + X^2 + 1$).
- **Длительность бита**: 66 полных периодов несущей ($544 \times 66 = 35\,904$ тактов $\approx 427.4\text{ мкс}$).
- **Общая длительность пачки**: 2046 периодов несущей ($\approx 13.25\text{ мс}$).

---

## 2. Аппаратная архитектура и тайминги

### Тактирование
- Внешний кварцевый генератор 16 МГц на выводе `PF0` (HSE Bypass).
- PLL конфигурирует системную частоту **SYSCLK = 84 МГц**.

### Генерация несущей и комплементарный ШИМ (`TIM1`)
- Таймер `TIM1` работает в режиме генерации комплементарного ШИМ с мертвовым временем (Dead-Time):
  - `PA8` (`TIM1_CH1`): прямой выход.
  - `PB13` (`TIM1_CH1N`): инверсный выход.
- Управляет силовым полумостовым/мостовым драйвером резонансного контура.
- Переключение фазы/манипуляция кодом выполняется на лету при выдаче бит M-последовательности.

### Нулевой фазовый дрейф 2.0-секундного цикла (`TIM5`)
- Базовый период формируется 32-битным аппаратным таймером `TIM5`:
  - `PSC = 0`, `ARR = 167 999 999` (ровно $168\,000\,000$ тактов).
- Таймер работает в режиме циклического автоперезапуска (`TIM_CR1_ARPE`).
- Фаза синхронизируется по аппаратному флагу обновления `TIM_SR_UIF` без программного обнуления `TIM5->CNT`, что полностью исключает накопление джиттера и фазовой погрешности во времени.

---

## 3. Динамическое управление питанием (Power Saving)
Для минимизации нагрева и потребления тока в скважине в паузе между синхропосылками ($\approx 1.98\text{ с}$) аналоговая и силовая часть обесточиваются:

1. За **$30\text{ мс}$** до момента излучения включается высоковольтный преобразователь: `PB14` (`DIS_TPS` = 1).
2. За **$10\text{ мс}$** до излучения активируется мостовой драйвер: `PB11` (`DIS_DRV` = 0).
3. Излучается пачка 31-битного кода ($13.25\text{ мс}$), зажигается индикатор `LED_TX` (`PA5`).
4. Сразу после окончания пачки драйвер блокируется (`DIS_DRV` = 1), преобразователь отключается (`DIS_TPS` = 0), индикатор гаснет.

---

## 4. Режим стендовой настройки контура (TUNE / SWEEP)
Используется **только на этапе лабораторной/стендовой сборки и настройки** прибора для подбора резонансного конденсатора излучающего контура:

- По сервисному UART интерфейсу (`PA9/PA10`, 115200 8N1) отправляется команда непрерывного ШИМ: `GTUN<ARR>` (например, `GTUN544`).
- Передатчик переходит в режим `work_mode = TUNE`, непрерывно выдавая несущую на силовой контур.
- Инженер снимает резонансную кривую $V_{\text{вых}}(f)$ с помощью осциллографа и рассчитывает оптимальную емкость подстроечного конденсатора по формуле Томсона:
  $$C = \frac{1}{(2\pi f_0)^2 \cdot L}$$
- Команда `GNOR` возвращает передатчик в штатный рабочий режим импульсов $2.0\text{ с}$ (`work_mode = NORM`).
- Прием команд реализован на базе кольцевого буфера и неблокирующего конечного автомата, не влияющего на точность основных таймеров.

## 5. Карта выводов (Pinout LQFP48)

| Вывод | Имя в коде | Режим периферии | Описание |
|---|---|---|---|
| **PA0** | `SYNC_OUT` | `GPIO_Output` | Контрольный импульс синхронизации |
| **PA5** | `LED_TX` | `GPIO_Output` | Светодиодная индикация излучения (1 - ВКЛ) |
| **PA8** | `TIM1_CH1` | `Alternate Function` | Прямой ШИМ несущей $154.4\text{ кГц}$ |
| **PB13** | `TIM1_CH1N` | `Alternate Function` | Инверсный ШИМ несущей $154.4\text{ кГц}$ |
| **PB11** | `DIS_DRV` | `GPIO_Output` | Управление драйвером (0 - ВКЛ, 1 - ВЫКЛ) |
| **PB14** | `DIS_TPS` | `GPIO_Output` | Питание преобразователя TPS (1 - ВКЛ, 0 - ВЫКЛ) |
| **PA9** | `USART1_TX` | `Alternate Function` | Сервисный UART (115200 8N1) |
| **PA10** | `USART1_RX` | `Alternate Function` | Сервисный UART (115200 8N1) |
| **PF0** | `OSC_IN` | `RCC_OSC_IN` | Вход внешнего генератора 16 МГц (HSE Bypass) |
| **PA13** | `SWDIO` | `SYS_JTMS-SWDIO` | Интерфейс отладки и прошивки SWD |
| **PA14** | `SWCLK` | `SYS_JTCK-SWCLK` | Тактовый сигнал отладки SWD |

## 6. Сборка проекта
- Проект создан для **STM32CubeIDE** (GCC ARM Embedded).
- Конфигурация периферии: `ACUSRIC_TX_474.ioc`.
- Оптимизация компилятора: `-O2` или `-Og` для отладки.
